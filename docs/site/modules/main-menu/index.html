📋 Main Menu

User Story Development Guide · CardDemo Module

📋 Overview

Purpose: Present a role-appropriate menu after login, routing users to account, card, transaction, and payment functions.

Business Context: The main menu is the navigation hub for all regular user functions. It reads the user type from COMMAREA set during sign-on and presents only the options appropriate for that role. Admin users proceed to the Admin Menu (CA00) instead.

CM00 · COMEN01C

🎯 User Story Templates

  • As a regular user, I want to see menu options for account, cards, transactions, reports, and payments so that I can navigate to any function in one step.
  • As an admin user, I want to be routed to the Admin Menu after login so that I access only administrative functions.
  • As a user, I want the menu to display my name so that I know I am logged in with the correct identity.
