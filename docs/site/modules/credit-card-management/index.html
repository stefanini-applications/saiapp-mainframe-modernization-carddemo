💳 Credit Card Management

User Story Development Guide · CardDemo Module

📋 Overview

Purpose: List all credit cards on an account, view card details, and update card information such as active status and embossed name.

Business Context: Cards are the instruments used for transactions and authorizations. A single account can have multiple cards (one per cardholder). The cross-reference file (CARDXREF) links card numbers to customer and account IDs.

CCLI · COCRDLIC CCDL · COCRDSLC CCUP · COCRDUPC

🎯 User Story Templates

  • List Cards: As a regular user, I want to see all credit cards on my account so that I can select one to view or manage.
  • View Card Details: As a regular user, I want to view a card's number, expiration date, and status so that I know if it is active and valid.
  • Activate/Deactivate Card: As an admin, I want to update a card's active status so that I can block or restore a card.
  • Update Embossed Name: As an admin, I want to update the name on a card so that it reflects a name change.

Acceptance Criteria Examples

Given: user with ACCT-ID linked to 3 cards in CARDDATA.PS
When:  user navigates to Credit Card List (CCLI)
Then:  all 3 cards displayed with CARD-NUM, CARD-EXPIRAION-DATE, CARD-ACTIVE-STATUS

Given: admin changes CARD-ACTIVE-STATUS to N
When:  COCRDUPC processes the CCUP transaction
Then:  card record updated in VSAM CARDDATA.PS
And:   authorization requests for this card are declined

Given: CARD-EXPIRAION-DATE is in the past
When:  an authorization request is submitted for this card
Then:  authorization is declined with expiry reason code

Card Record (CVACT02Y — 150 bytes)

CARD-NUM               PIC X(16)  -- 16-digit primary key
CARD-ACCT-ID           PIC 9(11)  -- Linked account ID
CARD-CVV-CD            PIC 9(03)  -- CVV code
CARD-EMBOSSED-NAME     PIC X(50)  -- Name printed on card
CARD-EXPIRAION-DATE    PIC X(10)  -- YYYY-MM-DD
CARD-ACTIVE-STATUS     PIC X(01)  -- Y=Active, N=Inactive

Cross-Reference (CVACT03Y — 50 bytes)

XREF-CARD-NUM   PIC X(16)  -- Card number
XREF-CUST-ID    PIC 9(09)  -- Customer ID
XREF-ACCT-ID    PIC 9(11)  -- Account ID

📊 Complexity Guidelines

Simple (1–2 pts) List cards for an account; view card detail screen
Medium (3–5 pts) Update card active status; update embossed name; handle card not found
Complex (5–8 pts) Reissue card with new number; update cross-reference and card file atomically; card fraud block with audit log

⚡ Development Acceleration

  • CARDXREF for lookups: CVACT03Y gives the account-to-card relationship; no table scan needed
  • AIX on CARDDATA: Alternate index available for account-based card list queries
  • Sample data: app/data/ASCII/carddata.txt and cardxref.txt for development testing
  • Three-screen pattern: List → View → Update is already established; reuse the pseudo-conversational COMMAREA passing pattern
